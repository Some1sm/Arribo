### Delivery Mechanism for FGC Datasets (Feed D)

Inspection of `https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/<id>` and `.../records?limit=2`:

1. **GTFS-RT Datasets (`vehicle-positions-gtfs_realtime`, `trip-updates-gtfs_realtime`, `alerts-gtfs_realtime`)**:
   * **Delivery format**: They are **not** delivered as granular JSON transit entity records. Each dataset contains exactly **1 record** (`total_count: 1`) holding a single field named `file` (type `file`, description *"Arxiu per descarregar"*).
   * **Field structure**:
     ```json
     {"file": {"filename": "<name>.pb", "format": "pb", "id": "<hash>", "url": "<direct_download_url>"}}
     ```
   * **Direct Protobuf URLs**:
     * **Vehicle Positions** (`vehicleposition.pb`): [Direct PB URL](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/vehicle-positions-gtfs_realtime/files/d286964db2d107ecdb1344bf02f7b27b) ([API Dataset](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/vehicle-positions-gtfs_realtime))
     * **Trip Updates** (`tripupdates.pb`): [Direct PB URL](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/trip-updates-gtfs_realtime/files/735985017f62fd33b2fe46e31ce53829) ([API Dataset](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/trip-updates-gtfs_realtime))
     * **Service Alerts** (`alerts.pb`): [Direct PB URL](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/alerts-gtfs_realtime/files/02f92ddc6d2712788903e54468542936) ([API Dataset](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/alerts-gtfs_realtime))
2. **`posicionament-dels-trens` (Geotren)**:
   * **Delivery format**: Delivered as **JSON records** (one per active train, ~65 records) ([API Dataset](https://dadesobertes.fgc.cat/api/explore/v2.1/catalog/datasets/posicionament-dels-trens)).
   * **Fields**: `id`, `lin`, `geo_point_2d` (`lat`, `lon`), `dir`, `origen`, `desti`, `properes_parades` (semi-colon separated JSON fragments), `estacionat_a`, `en_hora`, `tipus_unitat`, `ut`, and car occupancy breakdowns (`ocupacio_mi_percent`, `ocupacio_mi_tram`, `ocupacio_ri_percent`, `ocupacio_m1_percent`, `ocupacio_m2_percent`).
